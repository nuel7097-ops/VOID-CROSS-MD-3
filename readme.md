## 🤖 Multi-User Telegram Pairing (New Feature)

This version of ༗༊𝐕𝐎𝐈𝐃-𝐂𝐑𝐎𝐒 𝐌𝐃彡★🦋❦ supports **multiple users** — each person pairs their own WhatsApp number and gets their own independent bot session running on their account.

### How It Works

1. You deploy ༗༊𝐕𝐎𝐈𝐃-𝐂𝐑𝐎𝐒 𝐌𝐃彡★🦋❦ once
2. **Each user** opens your Telegram bot and sends `/pair <their_phone_number>`
3. They receive an 8-digit pairing code via Telegram
4. They open WhatsApp → **Settings → Linked Devices → Link a Device → Link with phone number instead**
5. They enter the code — the bot is now running on **their own WhatsApp** ✅
6. They can use all bot commands directly on WhatsApp (e.g. `!help`, `!sticker`)
7. On restart, **all sessions restore automatically** — no one needs to re-pair

### Session Storage

Each user's WhatsApp session is stored in its own folder:
sessions/
  2348012345678/ ← User 1's session
  447911123456/ ← User 2's session
 ...

### Setup

**Step 1:** Create a Telegram bot via [@BotFather](https://t.me/BotFather)
- Send `/newbot` and follow the prompts
- Copy the **API token** you receive

**Step 2:** Set your token
- Copy `.env.example` to `.env`:
  ```bash
  cp .env.example .env
Set your token in :
  TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrstuvWXYZ
Step 3: Start the bot
npm start
Telegram Bot Commands
| Command | Description |
| `/start` | Welcome message & instructions |
| `/pair <phone>` | Connect your WhatsApp to the bot |
| `/sessions` | List all connected WhatsApp accounts |
| `/status` | Bot status and session count |
| `/help` | Show all commands |
Example:
/pair 2348012345678

📖 About

The ༗༊𝐕𝐎𝐈𝐃-𝐂𝐑𝐎𝐒 𝐌𝐃彡★🦋❦ WhatsApp Bot assists group admins by providing them with tools to efficiently manage large WhatsApp groups. The bot uses the Baileys library to interact with the WhatsApp Web API and supports multi-device features.

It is lightweight and can be easily customized to add more commands as per your requirements. The bot runs in a http://Node.js environment and provides QR code-based authentication to link your WhatsApp account.

---

🛠️ Setup & Installation

Prerequisites

http://Node.js installed on your system
Git installed (for cloning the repository)

Step-by-Step Setup

Clone the repository:
    git clone https://github.com/mruniquehacker/Knightbot-MD.git
    cd Knightbot-MD
Install the dependencies:
    npm install
Run the bot:
    node index.js
Scan the QR code:

    Once the bot starts, a QR code will appear in the terminal. Scan this QR code using the Linked Devices feature in WhatsApp to connect your WhatsApp account with the bot.
